# Citation and License Notes

## Dataset citation

The upstream primary data are from the Global Urban Heat Island Intensity Dataset on Figshare, DOI [10.6084/m9.figshare.24821538](https://doi.org/10.6084/m9.figshare.24821538). Cite the dataset's official record and follow its own terms when reusing the data.

## Project code license

No project-code license is set in this package. Because the repository combines work from multiple collaborators and relies on upstream datasets/services, agree on the code license with all contributors before adding a license file. Publishing a repository without a license does not automatically grant other users permission to reuse the code.
