# Data Quality Audit Notes

This note separates checks performed on uploaded files from checks that still require the full local source archive.

## City metadata and country mapping — checked

- `data/reference/CityInfo.csv`: 10,196 rows and 10,196 unique `UrbanId` values.
- Canonical country mapping: 1,634 rows and 1,634 unique `UrbanId` values; its country counts are 1,451 China and 183 Türkiye before quarantine.
- Every mapping UrbanId exists in CityInfo.
- For all 1,634 matched UrbanIds, `Longitude`, `Latitude`, and `Area` match the CityInfo table exactly in the supplied files.
- `CityInfo_with_Country.csv` was regenerated by joining country only by `UrbanId`; the 8,562 rows without an explicit country mapping remain blank, not assigned via proximity.
- The mapping merge audit and the list of unmapped global city records are in `data/audit_reports/`.

## `Mod2` versus `AMod2` — do not conflate

The inspected `AMod2_Nig_2001_22.csv` and `Mod2_Nig_2001_22.csv` both have 10,196 records, but their `Intensity_MEA` values differ. They are distinct source products. The Phase 2 target protocol uses only exact `Mod2_Nig_YYYY_22.csv` files for the main target; `AMod2` samples are excluded from the active pipeline and must not be renamed to `Mod2`.
