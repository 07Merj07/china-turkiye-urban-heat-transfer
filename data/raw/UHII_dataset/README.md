# Local-only source data directory

Place the 80 exact source files here: `Mod2_Nig_YYYY_{6,7,8,22}.csv` for each year 2001–2020. Do not rename `AMod2`, `SMod2`, `Day`, `EA`, `IEA`, or `DEA` files to match. Use `scripts/copy_required_uhi_files.ps1` to copy the required files from the original data folder without moving or renaming them. The actual CSV files are ignored by Git.
