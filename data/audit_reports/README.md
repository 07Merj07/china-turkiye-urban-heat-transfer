# Data audit reports

- `city_mapping_merge_audit.csv`: checks for the current ID-based merge.
- `CityInfo_rows_without_country_mapping.csv`: global CityInfo rows for which the reviewed China/Türkiye mapping has no country. This is not a list of errors; it reflects that CityInfo is global while the mapping covers only two countries.
- `sample_uhi_inventory.csv`: source checks for the five sample files only.
- `historical_user_audits/` and `historical_external_feature_audits/` contain older reports from the original project. They predate the final 1,621-city Phase 2 cohort and must not be described as the final Phase 2 audit.
